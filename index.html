🎉 งาน

กรอบที่ให้แขกเลือก (เลือกกรอบเดียว แขกจะข้ามหน้าเลือกกรอบไปถ่ายเลย)

ถ้าไม่เลือกข้อนี้ แขกแค่กดถ่าย แล้วไปหน้ารับรูป (QR / ปริ้น) ทันที

🖨 ปริ้น

ปริ้นลงกระดาษ 4x6 นิ้ว (กรอบแถบยาวได้ 2 แถบ ตัดครึ่งแบ่งกันได้) · อยากให้ปริ้นทันทีโดยไม่มีหน้าต่างถาม ให้เปิด Chrome ด้วยตัวเลือก --kiosk-printing (ดู README)

📱 QR Code ให้แขกโหลดรูป

ใช้ Cloudinary (ฟรี) เป็นที่เก็บรูป ถ้าไม่ตั้งค่า จะไม่มี QR แต่ยังปริ้นได้ และรูปทุกชุดจะเก็บไว้ในเครื่องนี้

วิธีตั้งค่า Cloudinary (ทำครั้งเดียว ~5 นาที)
  1. สมัครฟรีที่ cloudinary.com
  2. หน้า Dashboard คัดลอก Cloud name มาใส่ช่องด้านล่าง
  3. ไปที่ Settings → Upload → Upload presets → Add upload preset
  4. ตั้ง Signing mode เป็น Unsigned แล้วกด Save
  5. คัดลอกชื่อ preset มาใส่ช่องด้านล่าง แล้วกด "ทดสอบอัปโหลด"
📺 จอ QR แยก

เปิดลิงก์นี้บนทีวี/แท็บเล็ตข้างตู้ จะแสดงรูปล่าสุดพร้อม QR ให้แขกสแกน · ถ้าเปิดบนเครื่องอื่นที่ไม่ใช่เครื่องตู้ ต้องเปิด Resource list ใน Cloudinary ก่อน (Settings → Security → Restricted media types → เอาติ๊ก Resource list ออก)
