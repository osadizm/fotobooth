# Photobooth

เว็บถ่ายรูปพร้อมกรอบ ใช้ได้ทั้งบนคอม แท็บเล็ต และมือถือ ไม่ต้องติดตั้งโปรแกรม และไม่ต้องมีเซิร์ฟเวอร์หลังบ้าน

## วิธีใช้ (สำหรับแขก)
1. กด **เริ่มเลย** แล้วเลือกกรอบ
2. กดปุ่ม **ถ่าย** ครั้งเดียว ระบบจะนับถอยหลังและถ่ายให้จนครบทุกช่อง
3. เลือกโทนสี แล้วกด **บันทึกรูป / ปริ้น / แชร์**
   - แตะรูปช่องไหนก็ได้ เพื่อถ่ายช่องนั้นใหม่
   - กด **เปลี่ยนกรอบ** ได้ทุกเมื่อ รูปที่ถ่ายไว้จะย้ายไปอยู่ในกรอบใหม่ให้เอง

## ตั้งค่า (ปุ่ม ⚙️ มุมขวาบน)
- ข้อความบนกรอบ เช่น ชื่องาน, จะแสดงวันที่หรือไม่
- เลือกกล้อง (เช่น กล้องที่ต่อเป็นเว็บแคม), กลับด้านรูป, เปิด/ปิดเสียง
- **โหมดตู้**: ถ้าไม่มีคนใช้ตามเวลาที่ตั้งไว้ จะกลับไปหน้าแรกเอง

## การเปิดใช้งาน
กล้องจะทำงานได้เฉพาะเมื่อเปิดหน้าเว็บผ่าน **https** หรือ **localhost** เท่านั้น
- ทดสอบในเครื่อง: เปิด terminal ในโฟลเดอร์นี้ แล้วรัน `python -m http.server 8000` จากนั้นเปิด http://localhost:8000
- ใช้งานจริง: อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages, Netlify หรือเว็บโฮสต์ใดก็ได้ที่เป็น https

## การปริ้น
รูปจะปริ้นลงกระดาษ 4x6 นิ้ว ถ้าเป็นกรอบแถบยาว จะได้ 2 แถบในแผ่นเดียว (ตัดครึ่ง)
ถ้าอยากให้ปริ้นทันทีโดยไม่มีหน้าต่างถาม ให้เปิด Chrome ด้วยตัวเลือก `--kiosk-printing`

## เพิ่มกรอบเอง
กรอบทั้งหมดอยู่ใน `js/frames.js` คำอธิบายรูปแบบอยู่ที่ส่วนหัวของไฟล์
แต่ละกรอบกำหนด 4 อย่าง:
- ขนาดภาพ
- ตำแหน่งช่องรูป (สี่เหลี่ยม วงกลม โค้ง หลายเหลี่ยม หรือหมุนเอียงได้)
- `bg` สำหรับวาดพื้นหลัง
- `fg` สำหรับวาดข้อความหรือของตกแต่งทับรูป

เพิ่มกรอบใหม่แล้วจะขึ้นในหน้าเลือกกรอบโดยอัตโนมัติ

## ไฟล์
```
index.html      หน้าเว็บ
css/style.css   หน้าตา
js/frames.js    คลังกรอบรูป
js/app.js       การทำงาน (กล้อง ถ่าย ฟิลเตอร์ บันทึก ปริ้น)
```
